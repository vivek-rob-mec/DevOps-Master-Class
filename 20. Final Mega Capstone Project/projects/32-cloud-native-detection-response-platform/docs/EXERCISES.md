# Required exercises

1. Generate a controlled shell event in a disposable cluster.
2. Replay the fixtures and add a negative test before tuning a rule.
3. Correlate a service account from runtime to Kubernetes and cloud audit logs.
4. Preserve and hash evidence before containment.
5. Compare detect-only and enforce modes for a Tetragon policy.
6. Run a tabletop credential-theft incident with communications and recovery gates.
