# SLSA controls and evidence

Target Build L2 first: hosted build, platform-generated signed provenance, immutable artifact identity, and consumer verification. Treat L3 as a build-platform assessment rather than a workflow checkbox. Retain source revision, builder identity, parameters, dependency lockfiles, SBOMs, vulnerability exceptions, signatures, attestations, promotion approval, admission result, and rollback digest. Verify evidence from a separate trust domain before production promotion.
